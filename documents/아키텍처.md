# 🏗️ AI Agent 아키텍처

병원 탐색 AI 에이전트 시스템 아키텍처 문서

<br>

## 1. 전체 아키텍처

### 주요 특징

- **대화 영구 저장**: PostgreSQL 기반 대화 히스토리 저장
- **멀티턴 대화**: session_id 기반 컨텍스트 관리
- **서버 재시작 후에도 대화 유지**: PostgresSaver + ConnectionPool

```mermaid
graph TB
    subgraph Client["클라이언트 (향후 Streamlit)"]
        C[사용자]
    end

    subgraph Backend["FastAPI Backend"]
        API[FastAPI 서버]
        Router[API v1 Router]
        Endpoint[Chat Endpoint]

        subgraph Service["Service Layer"]
            ChatService[Chat Service]
        end

        subgraph Core["Core Layer"]
            Agent[LangGraph Agent]

            subgraph LLM_Module["LLM Module"]
                LLM_Init[__init__.py]
                Gemini[gemini.py]
                GPT[gpt.py]
            end

            subgraph Tools_Module["Tools Module"]
                ToolRegistry[Tool Registry<br/>동적 도구 등록 관리]
                ToolFactory[Tool Factory<br/>도구 생성 및 초기화]
            end

            subgraph Database_Module["Database Module"]
                DB[database.py<br/>DB 연결 관리]
                PostgresSaver[PostgresSaver<br/>대화 영구 저장]
            end
        end

        subgraph Models["Model Layer"]
            Schema[Pydantic Schemas]
        end
    end

    subgraph Database["PostgreSQL Database"]
        CheckpointsTable[(checkpoints 테이블<br/>대화 히스토리)]
    end

    C -->|POST /api/v1/chat| API
    API --> Router
    Router --> Endpoint
    Endpoint --> ChatService
    ChatService --> Agent
    Agent --> LLM_Init
    LLM_Init --> Gemini
    LLM_Init --> GPT
    Agent --> DB
    DB --> PostgresSaver
    PostgresSaver -->|영구 저장| CheckpointsTable
    Agent --> ToolRegistry
    ToolRegistry --> ToolFactory
    Endpoint --> Schema
```

## 2. 데이터 흐름

```mermaid
sequenceDiagram
    participant C as 클라이언트
    participant API as FastAPI
    participant Endpoint as Chat Endpoint
    participant Service as Chat Service
    participant Agent as LangGraph Agent
    participant DB as database.py
    participant PostgresSaver as PostgresSaver
    participant PostgreSQL as PostgreSQL DB
    participant LLM as LLM (Gemini/GPT)
    participant Tool as Tool Registry

    C->>API: POST /api/v1/chat<br/>{session_id, message}
    API->>Endpoint: 라우팅
    Endpoint->>Service: process_chat(request)
    Service->>Agent: agent.invoke({messages}, config)

    Note over Agent,PostgreSQL: 대화 컨텍스트 조회 (PostgreSQL)
    Agent->>DB: get_postgres_checkpointer()
    DB->>PostgresSaver: PostgresSaver 인스턴스
    Agent->>PostgresSaver: 이전 대화 조회<br/>(session_id = thread_id)
    PostgresSaver->>PostgreSQL: SELECT * FROM checkpoints<br/>WHERE thread_id = ?
    PostgreSQL-->>PostgresSaver: 대화 히스토리
    PostgresSaver-->>Agent: 대화 히스토리 반환

    Note over Agent,LLM: 응답 생성
    Agent->>LLM: 메시지 + 히스토리 전달
    LLM-->>Agent: 초기 응답

    alt Tool 사용 필요
        Agent->>Tool: get_hospital_info("서울대병원")
        Tool-->>Agent: 병원 정보 반환
        Agent->>LLM: Tool 결과 포함 재요청
        LLM-->>Agent: 최종 응답
    end

    Note over Agent,PostgreSQL: 대화 저장 (영구 저장)
    Agent->>PostgresSaver: 대화 히스토리 업데이트
    PostgresSaver->>PostgreSQL: INSERT INTO checkpoints<br/>(thread_id, checkpoint, ...)
    PostgreSQL-->>PostgresSaver: 저장 완료

    Agent-->>Service: result (messages)
    Service-->>Endpoint: ChatResponse
    Endpoint-->>API: JSON 응답
    API-->>C: {session_id, response}
```
