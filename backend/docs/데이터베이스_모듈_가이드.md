### 1. 기본 개념

`get_db()`는 FastAPI 의존성으로 비동기 DB 커넥션을 제공하며, 자동 커밋/롤백을 처리합니다.

```python
from fastapi import Depends
from psycopg import AsyncConnection
from app.db import get_db

@app.get("/users/{user_id}")
async def get_user(user_id: int, conn: AsyncConnection = Depends(get_db)):
    # conn 사용 후 자동 커밋/롤백
    pass
```

## 📚 핵심 기능

### get_db() - FastAPI 의존성

비동기 DB 커넥션을 제공하며 트랜잭션을 자동 관리합니다.

```python
async def get_db() -> AsyncGenerator[AsyncConnection, None]:
    """
    - 정상 종료 시: 자동 커밋
    - 예외 발생 시: 자동 롤백
    - 연결 풀에서 자동 할당/반환
    """
```

### Checkpointer

LangGraph 에이전트의 대화 히스토리 저장용 (독립적인 연결 풀 사용):

```python
from app.db import get_postgres_checkpointer

checkpointer = get_postgres_checkpointer()
agent = create_react_agent(model=llm, tools=tools, checkpointer=checkpointer)
```

## 🔧 CRUD 예시

### Create (생성)

```python
from psycopg.rows import dict_row

@app.post("/users")
async def create_user(user_data: UserCreate, conn: AsyncConnection = Depends(get_db)):
    async with conn.cursor(row_factory=dict_row) as cur:
        await cur.execute(
            """
            INSERT INTO users (username, email, created_at)
            VALUES (%s, %s, NOW())
            RETURNING id, username, email, created_at
            """,
            (user_data.username, user_data.email)
        )
        return await cur.fetchone()
```

### Read (조회)

```python
@app.get("/users/{user_id}")
async def get_user(user_id: int, conn: AsyncConnection = Depends(get_db)):
    async with conn.cursor(row_factory=dict_row) as cur:
        await cur.execute(
            "SELECT id, username, email, created_at FROM users WHERE id = %s",
            (user_id,)
        )
        return await cur.fetchone()
```

### Update (수정)

```python
@app.put("/users/{user_id}")
async def update_user(
    user_id: int,
    user_data: UserUpdate,
    conn: AsyncConnection = Depends(get_db)
):
    async with conn.cursor(row_factory=dict_row) as cur:
        await cur.execute(
            """
            UPDATE users
            SET email = %s, updated_at = NOW()
            WHERE id = %s
            RETURNING id, username, email, updated_at
            """,
            (user_data.email, user_id)
        )
        return await cur.fetchone()
```

### Delete (삭제)

```python
@app.delete("/users/{user_id}")
async def delete_user(user_id: int, conn: AsyncConnection = Depends(get_db)):
    async with conn.cursor() as cur:
        await cur.execute("DELETE FROM users WHERE id = %s", (user_id,))
        return {"deleted": cur.rowcount > 0}
```

## 🔄 트랜잭션 관리

`get_db()`는 자동으로 트랜잭션을 관리합니다:

```python
async def transfer_money(
    from_id: int, to_id: int, amount: float,
    conn: AsyncConnection = Depends(get_db)
):
    async with conn.cursor() as cur:
        await cur.execute(
            "UPDATE accounts SET balance = balance - %s WHERE id = %s",
            (amount, from_id)
        )
        await cur.execute(
            "UPDATE accounts SET balance = balance + %s WHERE id = %s",
            (amount, to_id)
        )
    # 성공 시 자동 commit, 예외 시 자동 rollback
```

## 🏗️ 애플리케이션 생명주기

연결 풀은 첫 `get_db()` 호출 시 자동 생성되며, 애플리케이션 종료 시 정리가 필요합니다:

```python
from contextlib import asynccontextmanager
from fastapi import FastAPI
from app.db import close_db_connections, close_checkpointer

@asynccontextmanager
async def lifespan(app: FastAPI):
    print("🚀 Application starting...")
    yield
    await close_db_connections()
    close_checkpointer()
    print("👋 Application shutdown")

app = FastAPI(lifespan=lifespan)
```

## ⚠️ 핵심 주의사항

### 1. SQL Injection 방지

```python
# ✅ 올바름 - 파라미터 바인딩
await cur.execute("SELECT * FROM users WHERE id = %s", (user_id,))

# ❌ 위험 - SQL Injection 취약
await cur.execute(f"SELECT * FROM users WHERE id = {user_id}")
```

**🚨중요**: 절대 f-string이나 문자열 포매팅으로 SQL 생성하지 말 것!

### 2. row_factory 선택

```python
# dict 반환 (권장) - JSON 변환 쉬움
cursor(row_factory=dict_row)

# tuple 반환 (기본) - 메모리 효율적
cursor()
```

## 🧪 테스트

```python
import pytest
from psycopg_pool import AsyncConnectionPool
from psycopg.rows import dict_row

@pytest.fixture
async def test_db():
    pool = AsyncConnectionPool(
        "postgresql://test_user:test_pass@localhost:5432/test_db",
        min_size=1, max_size=2
    )
    await pool.open()
    async with pool.connection() as conn:
        yield conn
    await pool.close()

async def test_create_user(test_db):
    async with test_db.cursor(row_factory=dict_row) as cur:
        await cur.execute(
            "INSERT INTO users (username, email) VALUES (%s, %s) RETURNING *",
            ("testuser", "test@example.com")
        )
        user = await cur.fetchone()
        assert user["username"] == "testuser"
```
